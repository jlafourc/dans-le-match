# Enchaînement des choix de gestes

L’utilisateur précise que la rupture vient du bouton entre les questions, et non de l’animation. Après une bonne réponse, afficher une confirmation courte pendant 650 ms puis avancer automatiquement : premier geste vers second geste, second geste vers démonstration. Conserver l’explication et le bouton de nouvel essai en cas d’erreur.

Le timer est annulé à chaque changement d’écran ; son callback vérifie qu’il s’applique toujours à la même session. Les choix sont désactivés pendant la confirmation. Le déplacement vers une erreur conserve le focus sur son explication ; une réussite avance le focus vers la nouvelle question.

Vérifications : tests de délai, annulation et absence d’avancement sur erreur ; parcours mobile réel avec erreur, nouvel essai et deux bonnes réponses sans bouton intermédiaire ; sortie vers l’accueil pendant une confirmation et ouverture d’une nouvelle mission ; compilation et publication GitHub Pages.
